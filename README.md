# 理一下 · kp-sum-up

> **KP Pure Tools（知识宫殿纯净工具）**：可独立运行，不属于知识宫殿挂载体系。
> 「X一下」轻量技能家族 ④ —— 把一段时间的记录汇总成总结与计划。
> Version 1.0 · 2026-09-30 · 创作者：王亚宁（kp-wyn）

## 家族导航

| 口令 | 技能 | 状态 | 干什么 |
| --- | --- | --- | --- |
| 记一下 | kp-remember | 已推出 | 原样接住、零加工 |
| 收拾一下 | kp-tidy-up | 已推出 | 批量整理积压旧笔记 |
| 消化一下 | kp-digest | 挂载版已建／对外即将推出 | 当场提炼新碎片为要点／知识卡 |
| 理一下 | kp-sum-up | 已推出（本技能） | 汇总记录成总结与计划 |

## 特性

- **自动分类**：已完成、待办、日程、重要约定，不用人工分拣；
- **可视化 ＋ PDF**：生成干净的 HTML，导出可直接发送的 PDF；
- **周期复盘**：周／月／项目阶段／客户沟通汇总；
- **纯净独立**：不依赖知识宫殿，与 `kp-remember` 配合最佳。

## 快速开始

直接说“理一下，做个本周工作总结计划”，它读取记录、自动分类，输出 HTML ＋ PDF。

> English: Say “sum up this week” — it reads your records, categorizes them, and outputs a visual HTML page plus a shareable PDF.

## 安装方法

1. 仓库页点 **Code → Download ZIP**；
2. 解压，把技能文件夹（若带 `-main` 后缀则去掉，命名为 `kp-sum-up`）复制到 AI 的 `.user_skills/` 目录；
3. 重启 AI，即可用口令触发。

## 输出

```
总结_项目名_20260920.html   # 可视化网页版
总结_项目名_20260920.pdf    # 可直接对外发送
```

HTML 含：数据概览、已完成事项、待办（带优先级）、日程安排、重要约定。

## 支持类型

周总结／周计划、月度总结／月计划、项目阶段总结、客户沟通记录汇总。

## 注意事项

- KP 纯净工具，不属于知识宫殿挂载体系；
- 只整理与排版，不凭空创作内容；
- 数据来自 kp-remember 的记录，无记录时会提示先记；
- 本地生成，无需 API Key。
